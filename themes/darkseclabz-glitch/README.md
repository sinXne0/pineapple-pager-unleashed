# Darkseclabz Glitch

Darkseclabz design and skull artwork on the official Wargames theme by Hak5.

- Theme release 1.0.0
- Target firmware WiFi Pineapple Pager 2.0.0-stable
- Wargames baseline 2.0.0 and theme framework 0.9
- Offline checks against the official firmware image and public Wargames source
- Physical screen, launch, and navigation tests pending

Copy this entire directory to /root/themes/ or /mmc/root/themes/ and choose Darkseclabz Glitch in Settings → General → Theme.

Wargames layout and retained assets are by Hak5. See the [official theme repository](https://github.com/hak5/wifipineapplepager-themes) and [Hak5 Software License Agreement](https://hak5.org/license).
